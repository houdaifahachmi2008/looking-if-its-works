            Stappenplan Gmail (aanbevolen)
            
    
              
  1. Klik hierboven op Gmail.
    2. 
              
  2. Zet tweestapsverificatie aan: myaccount.google.com/signinoptions/twosv
    3. 
              
  3. Maak een app-wachtwoord aan: myaccount.google.com/apppasswords. Geef het de naam “Sitevo”.
    4. 
              
  4. Google toont 16 letters. Plak die bij Wachtwoord. Je gewone Gmail-wachtwoord werkt hier niet.
    5. 
              
  5. Vul bij Gebruiker je volledige Gmail-adres in en klik op Verbinding testen.
    6. 
            

            
Antwoorden van klanten gaan naar het e-mailadres bij “Jouw gegevens”, dus dat mag gewoon je Outlook-adres blijven.

          

          

            Stappenplan Outlook
            
    
              
  1. Klik hierboven op Outlook.
    2. 
              
  2. Zet tweestapsverificatie aan op account.microsoft.com/security.
    3. 
              
  3. Ga daar naar Geavanceerde beveiligingsopties → App-wachtwoorden en maak er een aan.
    4. 
              
  4. Plak dat wachtwoord bij Wachtwoord en klik op Verbinding testen.
    5. 
            

            
Microsoft blokkeert dit steeds vaker. Lukt het niet, gebruik dan Gmail.
